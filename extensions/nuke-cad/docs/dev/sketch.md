# Sketch

Client-side sketcher: solver adapter, primitive contract, the three UI layers, snap, and viewport picking.

- The solver is client-side only; the document stores planegcs-verbatim primitives with solved coordinates and the Python backend never re-solves (`python/sketch_builder.py` consumes solved primitives into build123d `Face` objects on the datum plane).
- Solver adapter: `src/common/sketch-solver.ts` exports the solver-agnostic `SketchSolver` interface and the `PlanegcsSketchSolver` implementation. No other source file imports `@salusoft89/planegcs` directly.
- `@salusoft89/planegcs` is pinned exact in `package.json` (1.2.0). The LGPL-2.0-or-later WASM bundles via webpack `asset/resource`; its public URL resolves through `require()` in `src/browser/sketch/planegcs-wasm-url.ts`. Vendoring the WASM is the documented fallback if the npm package stalls.
- Curve-level constraints (horizontal, radius, tangency, point-on-object, …) apply to lines/circles/arcs only. Ellipses and B-splines accept point-level constraints on their points (center/focus/poles), never curve-level ones, despite native PlaneGCS ellipse/B-spline constraint types. Also available: axis-locked DistanceX/DistanceY, Diameter, and Block (freeze-in-place, recorded as plain fixes).
- Ellipse and B-spline evaluation for rendering, snapping, and codegen (analytic ellipse polyline, De Boor sampling, clamped-uniform knots) lives in `src/common/sketch-curves.ts`, shared by the browser sketch layer and `src/common/python-codegen.ts`.
- Primitive JSON contract (planegcs-verbatim, camelCase aliases accepted): every primitive has `id`, `type`, optional `construction` (default `false`). `point`: `x`, `y`. `line`: `p1_id`/`p1Id`, `p2_id`/`p2Id`. `circle`: `c_id`/`centerId`, `radius`. `arc`: `c_id`/`centerId`, `radius`, `start_angle`/`startAngle`, `end_angle`/`endAngle`, `start_id`/`startId`, `end_id`/`endId` (radians). `ellipse`: `c_id`/`centerId`, `focus1_id`/`focus1Id`, `radmin` — the focus sets the major-axis direction and focal distance, so the major semi-axis is `sqrt(radmin² + |c − f1|²)` and `radmin` is the minor semi-axis. `bspline`: `pole_ids`/`poleIds`, `weights`, `knots`, `mult`, `degree`, `periodic` — OpenCASCADE compressed knots with invariant `sum(mult) == len(pole_ids) + degree + 1` (clamped non-periodic); only unit weights and `periodic: false` are buildable, and clamped knots interpolate the first/last poles as wire endpoints.
- Three layers, one responsibility each:
  - `src/browser/sketch/sketch-session.ts` — pure controller: tool state, snap, auto-constraints, constraint/dimension management, drag solving, external-geometry list, `SketchDef` serialization. No UI or three.js imports.
  - `src/browser/sketch/sketch-mode-controller.ts` — viewport wiring: orthographic camera, pointer-to-plane mapping, primitive plus dashed-construction rendering, pointer routing.
  - `src/browser/widgets/cad-viewport/cad-sketch-overlay.tsx` — React chrome: sketch toolbar with external-geometry tool, datum picker with sketch-on-face button, document toolbar, feature-creation dialog, constraint value input, dimension labels/popover, parameters panel, external-geometry list, carbon-copy button (imports the Feature-Tree-selected sketch with fresh ids), transform group (move/copy/rotate/mirror gestures plus scale/array/offset popovers and immediate join; offset has an auto-trim checkbox, miter-join, default on), remove-redundants button (session fixpoint), diagnostics popover (reference-resolution status, conflicting/redundant/partially-redundant tags, missing-coincident and open-profile warnings, fully-constrained flag), and the status line.
- Tools and keys: single-key shortcuts (S select, L line, C circle, A arc, R rectangle, P point, E ellipse, B B-spline, O slot, T trim, X extend, D split, J sketch-fillet, K sketch-chamfer, W polyline, Y polygon, U arc-slot, V move, G copy, I rotate, N mirror; M cycles tool modes), guarded against pick modes, dialogs, measure, text fields, and modifiers. Escape falls through: dismiss auto-dimension/constraint popover, cancel in-progress entity, clear selection, return to Select. The B-spline tool finishes on Enter/double-click (`SketchSession.finish()`, commits at two or more poles; a lone pole is discarded). The ellipse tool rejects an equal-radius third click (that would be a circle) and clamps a minor radius above the major radius, both via transient `SketchStatus.hint`. Ctrl+click on exactly two entities opens the relation popover (`constraint-relations.ts`). Auto-dimension (`nukeCad.sketchAutoDimension`, default false) inlines a value input after a line/circle/arc; Enter creates a driving dimension, Escape dismisses. A cheat-sheet popover on the toolbar header lists bindings.
- Panels: the sketch toolbar is a floating draggable panel (header/collapsed-toggle drag, right-click/double-click reset, position persists across collapse/expand). Dragging is shared (`draggable-panel.ts`: `useDraggablePanel`, header gates, `clampPanelPosition` with a 32px reachable sliver). Parameters, Solver Diagnostics, External Geometry, Keyboard Shortcuts, and Measurements panels share the header-drag grammar; the feature-creation modal drags by its NukeDialog header while the dimension value popover stays anchored. Toolbar body is a grouped two-column grid (draw / modify & constraint / lists) with `active` tool states. Sketch mode exits via the **Finish Sketch** pill (top-right; constraint bar owns top-center). Dimension labels auto-shift apart on screen-projection overlap; a dragged label pins a session-scoped screen offset (survives zoom/pan, opts out of auto-shift; dies with the session/dimension).
- Chrome components: `NukeToolbar`/`NukeToolbarGroup` for the icon-only document toolbar (Document/Sketch/Additive/Boolean/Dress-up/Pattern/Hole groups, tooltips, wrapping, no overflow menu), `NukeDialog` for the feature-creation modal, `NukePanel` for the parameters/diagnostics/external-geometry popovers.
- Snap is session-scoped and toggleable: `SketchSession.setSnapEnabled(on)` / `setSnapRadius(px)` (default 12px; disabling short-circuits endpoint/center/grid snaps and the auto-coincident/point-on-object paths), via `SketchModeController`; the toolbar has a magnet toggle plus S/M/L radius control (6/12/24px) reflected in the status line.
- Sketch-on-face and external geometry picking:
  - The Sketch Plane picker's **On Face…** button enters face-pick mode; hover highlights, click creates a `face` datum and enters sketch mode. Right-click/Escape cancels. All pick-mode banners (datum, external geometry, dress-up, hole, sweep/pipe curve) are click-through (`pointer-events: none` except Cancel) so faces under the banner stay pickable.
  - The **External Geometry** tool targets the most recent non-suppressed solid-producing feature and enters face-pick mode; clicks add a `TopologyRef` to the sketch's `externalRefs`. Resolved entities project into the sketch plane and render as dashed construction after the next rebuild (see `backend-pipeline.md`).
  - Face picking is `face-picker.ts` (`raycastFace`, `buildTopologyRef`, `FaceHighlighter`); edge picking for dress-ups is `edge-picker.ts` (`raycastEdge`, `EdgeHighlighter`) over a tessellation-built edge topology map. One viewport mesh per face carries the geometric fingerprint in `userData`, so picks read `userData.faceId` directly; edge fingerprints derive from curve data.
